\begin{problem}[43.4]
  Find all conjugates in $\C$ of $\sqrt{2} - \sqrt{3}$ over $\Q$.
\end{problem}

\begin{solution}
  Let $x = \sqrt{2} - \sqrt{3}$. Squaring both sides, we get:
  \[%
    x^2 = (\sqrt{2} - \sqrt{3})^2 = 2 - 2\sqrt{6} + 3 = 5 - 2\sqrt{6}
  .\]%
  Re-arranging, we get $-x^2 + 5 = 2\sqrt{6}$. Squaring both sides again, we get:
  \[%
    (x^2 - 5)^2 = 4 \cdot 6 = 24
  .\]%
  Expanding the left-hand side, we get $x^4 - 10x^2 + 25 = 24$. Re-arranging, we get $x^4 - 10x^2 + 1 = 0$.

  We show that $f(x) = x^4 - 10x^2 + 1$ is a minimal polynomial of $x$ over $\Q$. Since $f(x)$ is a monic polynomial with rational coefficients, it suffices to show that $f(x) = 0$ and that $f(x)$ is irreducible over $\Q$. Clearly, $f(x) = 0$ by construction.

  We now show that $f(x)$ is irreducible over $\Q$. We start by showing that $f(x)$ has no linear factors over $\Q$. Using the Rational Root Test, the only possible rational roots of $f(x)$ are $\pm 1$. We have $f(1) = 1 - 10 + 1 = -8 \neq 0$ and $f(-1) = 1 - 10 + 1 = -8 \neq 0$. Thus, $f(x)$ has no linear factors over $\Q$.

  Next, we show that $f(x)$ has no quadratic factors over $\Q$. If $f(x)$ has a quadratic factor over $\Q$, then it must be of the form $x^2 + ax + b$ for some $a, b \in \Q$. We have:
  \begin{align*}
    f(x) &= (x^2 + ax + b)(x^2 + cx + d) \\
    &= x^4 + (a + c)x^3 + (ac + b + d)x^2 + (ad + bc)x + bd
  .\end{align*}
  Comparing coefficients, we get the following system of equations:
  \begin{align*}
    a + c &= 0, \\
    ac + b + d &= -10, \\
    ad + bc &= 0, \\
    bd &= 1
  .\end{align*}
  From the first equation, we get $c = -a$. Substituting into the second equation, we get $-a^2 + b + d = -10$. Substituting into the third equation, we get $ad - ab = 0$, which implies that $d = b$. Substituting into the fourth equation, we get $b^2 = 1$, which implies that $b = \pm 1$. If $b = 1$, then we have $-a^2 + 1 + d = -10$, which implies that $d = -9 + a^2$. Substituting into the fourth equation, we get $1 \cdot (-9 + a^2) = 1$, which implies that $a^2 = 10$. This is not possible since $a \in \Q$. If $b = -1$, then we have $-a^2 - 1 + d = -10$, which implies that $d = -9 + a^2$. Substituting into the fourth equation, we get $(-1)(-9 + a^2) = 1$, which implies that $a^2 = 8$. This is not possible since $a \in \Q$. Thus, $f(x)$ has no quadratic factors over $\Q$.

  Lastly, we show that $f(x)$ has no cubic factors over $\Q$. If $f(x)$ has a cubic factor over $\Q$, then it must be of the form $x^3 + ax^2 + bx + c$ for some $a, b, c \in \Q$. We have:
  \begin{align*}
    f(x) &= (x^3 + ax^2 + bx + c)(x + d) \\
    &= x^4 + (a + d)x^3 + (b + ad)x^2 + (c + bd)x + cd
  .\end{align*}
  Comparing coefficients, we get the following system of equations:
  \begin{align*}
    a + d &= 0, \\
    b + ad &= -10, \\
    c + bd &= 0, \\
    cd &= 1
  .\end{align*}
  From the first equation, we get $d = -a$. Substituting into the second equation, we get $b - a^2 = -10$. Substituting into the third equation, we get $c - ab = 0$, which implies that $c = ab$. Substituting into the fourth equation, we get $ab(-a) = 1$, which implies that $a^2b = -1$. Substituting into the second equation, we get $b - a^2 = -10$, which implies that $b = -10 + a^2$. Substituting into the previous equation, we get $a^2(-10 + a^2) = -1$, which implies that $a^4 - 10a^2 + 1 = 0$. This is not possible since $a \in \Q$. Thus, $f(x)$ has no cubic factors over $\Q$.

  Therefore, $f(x)$ is irreducible over $\Q$, making $f(x)$ the minimal polynomial of $x$ over $\Q$.

  We now determine the conjugates of $\alpha$ over $\Q$. Recall that the conjugates of $\alpha$ are the images $\sigma(\alpha)$ under field embeddings:
  \[%
    \sigma : \Q(\alpha) \hookrightarrow \C \qtq{with} \sigma|_{\Q} = \Id
  .\]%
  Since $f(\alpha) = 0$ and $\sigma$ fixes $\Q$, we have:
  \[%
    0 = \sigma(f(\alpha)) = f(\sigma(\alpha))
  ,\]%
  so $\sigma(\alpha)$ must be a root of $f(x)$. Thus every conjugate of $\alpha$ is a root of its minimal polynomial.

  Conversely, if $\beta$ is any root of $f(x)$, then there exists an embedding:
  \[%
    \sigma : \Q(\alpha) \hookrightarrow \C \qtq{such that} \sigma(\alpha) = \beta
  .\]%
  Hence the conjugates of $\alpha$ are exactly the roots of $f(x)$.

  It remains to compute the roots of $f(x)$. Observe that
  \[%
    x^4 - 10x^2 + 1 = 0 \quad \Longleftrightarrow \quad x^2 = 5 \pm 2\sqrt{6}
  .\]%
  Therefore, the conjugates of $\alpha = \sqrt{2} - \sqrt{3}$ over $\Q$ are:
  \[%
    \sqrt{5 + 2\sqrt{6}}, \quad -\sqrt{5 + 2\sqrt{6}}, \quad \sqrt{5 - 2\sqrt{6}}, \quad -\sqrt{5 - 2\sqrt{6}}
  ,\]%
  which can be simplified to:
  \[%
    \sqrt{2} - \sqrt{3}, \quad -\sqrt{2} + \sqrt{3}, \quad \sqrt{2} + \sqrt{3}, \quad -\sqrt{2} - \sqrt{3}
  .\qedhere\]%
\end{solution}

\begin{problem}[43.5]
  Find all conjugates in $\C$ of $\sqrt{2} + i$ over $\Q$.
\end{problem}

\begin{solution}
  We start by finding the minimal polynomial of $\alpha = \sqrt{2} + i$ over $\Q$. We have $x^2 = (\sqrt{2} + i)^2 = 1 + 2\sqrt{2}i$. Re-arranging, we get $x^2 - 1 = 2\sqrt{2}i$. Squaring both sides, we get $x^4 - 2x^2 + 1 = -8$, which can be re-arranged to $x^4 - 2x^2 + 9 = 0$. Using the same procedure as Exercise 43.4, we can show that $f(x)$ is irreducible over $\Q$, making $f(x)$ the minimal polynomial of $\alpha$ over $\Q$.

  Again, using my work from Exercise 43.4, we can show that the conjugates of $\alpha$ over $\Q$ are exactly the roots of $f(x)$. We have:
  \[%
    x^4 - 2x^2 + 9 = 0 \quad \Longleftrightarrow \quad x^2 = 1 \pm 2i\sqrt{2}
  .\]%
  Thus, the roots of $f(x)$ are:
  \[%
    \sqrt{1 + 2i\sqrt{2}}, \quad -\sqrt{1 + 2i\sqrt{2}}, \quad \sqrt{1 - 2i\sqrt{2}}, \quad -\sqrt{1 - 2i\sqrt{2}}
  ,\]%
  which can be simplified to:
  \[%
    \sqrt{2} + i, \quad -\sqrt{2} - i, \quad \sqrt{2} - i, \quad -\sqrt{2} + i
  .\qedhere\]%
\end{solution}

\begin{problem}[43.6]
  Find all conjugates in $\C$ of $\sqrt{2} + i$ over $\R$.
\end{problem}

\begin{solution}
  We start by finding the vanishing. Since $\sqrt{2} \in \R$, we have $x - \sqrt{2} = i$. Squaring both sides, we get $(x - \sqrt{2})^2 = -1$, which can be re-arranged to $x^2 - 2\sqrt{2}x + 3 = 0$. Using the same procedure as Exercise 43.4, we can show that $f(x) = x^2 - 2\sqrt{2}x + 3$ is irreducible over $\R$, making $f(x)$ the minimal polynomial of $\alpha$ over $\R$.

  Again, using my work from Exercise 43.4, we can show that the conjugates of $\alpha$ over $\R$ are exactly the roots of $f(x)$. We have:
  \[%
    x^2 - 2\sqrt{2}x + 3 = 0 \quad \Longleftrightarrow \quad x = \sqrt{2} \pm i
  .\]%
  Thus, the conjugates of $\alpha$ over $\R$ are $\sqrt{2} + i$ and $\sqrt{2} - i$.
\end{solution}

\begin{problem}[43.7]
  Find all conjugates in $\C$ of $\sqrt{1 + \sqrt{2}}$ over $\Q$.
\end{problem}

\begin{solution}
  We start by finding the vanishing polynomial of $\alpha = \sqrt{1 + \sqrt{2}}$. Re-writing, we have $\alpha^2 - 1 = \sqrt{2}$. Squaring both sides, we get $\alpha^4 - 2\alpha^2 - 1 = 0$. Therefore, we have the vanishing polynomial $f(x) = x^4 - 2x^2 - 1$. Using the same procedure as Exercise 43.4, we can show that $f(x)$ is irreducible over $\Q$, making $f(x)$ the minimal polynomial of $\alpha$ over $\Q$.

  Now, applying the same procedure as Exercise 43.4, we can show that the conjugates of $\alpha$ over $\Q$ are exactly the roots of $f(x)$. We have:
  \[%
    x^4 - 2x^2 - 1 = 0 \quad \Longleftrightarrow \quad x^2 = 1 \pm \sqrt{2}
  .\]%
  Thus, the roots of $f(x)$ are:
  \[%
    \sqrt{1 + \sqrt{2}}, \quad -\sqrt{1 + \sqrt{2}}, \quad \sqrt{1 - \sqrt{2}}, \quad -\sqrt{1 - \sqrt{2}}
  .\qedhere\]%
\end{solution}

\begin{problem}[43.10]
  Compute $\tau_2(\sqrt{2} + \sqrt{5})$.
\end{problem}

\begin{solution}
  Computing $\tau_2(\sqrt{2} + \sqrt{5})$, we have:
  \begin{align*}
    \tau_2(\sqrt{2} + \sqrt{5}) &= \tau_2(\sqrt{2}) + \tau_2(\sqrt{5}) \\
                                &= -\sqrt{2} + \sqrt{5}
  .\qedhere\end{align*}
\end{solution}

\begin{problem}[43.12]
  Compute $(\tau_5\tau_3)\left(\frac{\sqrt{2} - 3\sqrt{5}}{2\sqrt{3} - \sqrt{2}}\right)$.
\end{problem}

\begin{solution}
  Computing $\tau_5\tau_3\left(\frac{\sqrt{2} - 3\sqrt{5}}{2\sqrt{3} - \sqrt{2}}\right)$, we have:
  \begin{align*}
    \tau_5\tau_3\left(\frac{\sqrt{2} - 3\sqrt{5}}{2\sqrt{3} - \sqrt{2}}\right) &= \tau_5\left(\frac{\tau_3(\sqrt{2}) - 3\tau_3(\sqrt{5})}{2\tau_3(\sqrt{3}) - \tau_3(\sqrt{2})}\right) \\
                                                                               &= \tau_5\left(\frac{\sqrt{2} - 3\sqrt{5}}{-2\sqrt{3} - \sqrt{2}}\right) \\
                                                                                &= \frac{\tau_5(\sqrt{2}) - 3\tau_5(\sqrt{5})}{-2\tau_5(\sqrt{3}) - \tau_5(\sqrt{2})} \\
                                                                                &= \frac{\sqrt{2} + 3\sqrt{5}}{-2\sqrt{3} - \sqrt{2}}
  .\qedhere\end{align*}
\end{solution}

\begin{problem}[43.15]
  Compute $\tau_3\tau_5\tau_3^{-1}(\sqrt{3} - \sqrt{5})$.
\end{problem}

\begin{solution}
  Computing $\tau_3\tau_5\tau_3^{-1}(\sqrt{3} - \sqrt{5})$, we have:
  \begin{align*}
    \tau_3\tau_5\tau_3^{-1}(\sqrt{3} - \sqrt{5}) &= \tau_3\tau_5\left(\frac{\sqrt{3} - \sqrt{5}}{\tau_3(\sqrt{3} - \sqrt{5})}\right) \\
                                                  &= \tau_3\tau_5\left(\frac{\sqrt{3} - \sqrt{5}}{-\sqrt{3} - \sqrt{5}}\right) \\
                                                  &= \tau_3\left(\frac{\tau_5(\sqrt{3}) - \tau_5(\sqrt{5})}{-\tau_5(\sqrt{3}) - \tau_5(\sqrt{5})}\right) \\
                                                  &= \tau_3\left(\frac{\sqrt{3} + \sqrt{5}}{-\sqrt{3} + \sqrt{5}}\right) \\
                                                  &= \frac{\tau_3(\sqrt{3}) + \tau_3(\sqrt{5})}{-\tau_3(\sqrt{3}) + \tau_3(\sqrt{5})} \\
                                                  &= \frac{-\sqrt{3} + \sqrt{5}}{\sqrt{3} + \sqrt{5}}
  .\qedhere\end{align*}
\end{solution}

\begin{problem}[43.18]
  Find the fixed field of the automorphism or set of automorphisms of $E$, $\{\tau_2, \tau_3\}$.
\end{problem}

\begin{solution}
  The automorphisms act on the basis elements of $E$ by changing signs. Specifically, $\tau_2$ maps $\sqrt{2} \mapsto -\sqrt{2}$ and fixes $\sqrt{3}, \sqrt{5}$ and $\tau_3$ maps $\sqrt{3} \mapsto -\sqrt{3}$ and fixes $\sqrt{2}, \sqrt{5}$. An element $\alpha \in E$ is written as:
  \[%
    \alpha = a_0 + a_1\sqrt{2} + a_2\sqrt{3} + a_3\sqrt{5} + a_4\sqrt{6} + a_5\sqrt{10} + a_6\sqrt{15} + a_7\sqrt{30}
  .\]%
  For $\tau_2(\alpha) = \alpha$, all terms involving $\sqrt{2}$ (i.e., $\sqrt{2}, \sqrt{6}, \sqrt{10}, \sqrt{30}$) must have coefficients equal to zero. This simplifies $\alpha$ to:
  \[%
    \alpha = a_0 + a_2\sqrt{3} + a_3\sqrt{5} + a_6\sqrt{15}
  .\]%
  For $\tau_3(\alpha) = \alpha$ on the remaining terms, all terms involving $\sqrt{3}$ (i.e., $\sqrt{3}, \sqrt{15}$) must have coefficients equal to zero. This leaves:
  \[%
    \alpha = a_0 + a_3\sqrt{5}
  .\]%
  Thus, the fixed field is $\{a_0 + a_3\sqrt{5} \mid a_0, a_3 \in \Q\}$, which is exactly $\Q(\sqrt{5})$.
\end{solution}

\begin{problem}[43.20]
  Find the fixed field of the automorphism or set of automorphisms of $E$, $\tau_5\tau_3\tau_2$.
\end{problem}

\begin{solution}
  Notice that the basis of $E$ is all products of $\sqrt{2}, \sqrt{3}, \sqrt{5}$, so it suffices to compute $\tau_5\tau_3\tau_2$ on these basis elements. We have:
  \begin{align*}
    \sigma(\sqrt{6}) &= \sigma(\sqrt{2})\sigma(\sqrt{3}) = -\sqrt{2} \cdot -\sqrt 3 = \sqrt{6} \\
    \sigma(\sqrt{10}) &= \sigma(\sqrt{2})\sigma(\sqrt{5}) = \sqrt{10} \\
    \sigma(\sqrt{15}) &= \sigma(\sqrt{5})\sigma(\sqrt{3}) = \sqrt{15} \\
    \sigma(\sqrt{30}) &= \sigma(\sqrt{2})\sigma(\sqrt{3})\sigma(\sqrt{5}) = -\sqrt{30}
  .\end{align*}
  Thus, for any $\alpha\in E$, we have $\sigma(\alpha) = -a - b\sqrt{2} - c\sqrt{3} - d\sqrt{5} + e\sqrt{6} + f\sqrt{10} + g\sqrt{15} - h\sqrt{30}$. So $\alpha = \sigma(\alpha)$ if and only if
  \begin{align*}
    a &= -a = 0 \\
    b &= -b = 0 \\
    c &= -c = 0 \\
    d &= -d = 0 \\
    e &= e \\
    f &= f \\
    g &= g \\
    h &= -h = 0
  .\end{align*}
  So the elements $\alpha \in E$ fixed by $\sigma$ are of the form $e\sqrt{6} + f\sqrt{10} + g\sqrt{15}$ which are exactly the elements of $\Q(\sqrt{6}, \sqrt{10}, \sqrt{15}) = \Q(\sqrt{6}, \sqrt{10})$. Thus $E_{\tau_5\tau_3\tau_2} = \Q(\sqrt{6}, \sqrt{10})$.
\end{solution}

\begin{problem}[43.22]
  \begin{enumerate}
    \item Show that each of the automorphisms $\tau_2$, $\tau_3$, and $\tau_5$ is of order 2 in $G(E/\Q)$. (Remember what is meant by the order of an element of a group.)
    \item Find the subgroup $H$ of $G(E/\Q)$ generated by the elements $\tau_2$, $\tau_3$, and $\tau_5$, and give the group table. [Hint: There are eight elements.]
    \item Just as was done in Example 43.4, argue that the group $H$ of part (b) is the full group $G(E/\Q)$.
  \end{enumerate}
\end{problem}

\begin{solution}[(i)]
  For $\tau_2$, we have $\tau_2(\sqrt{2}) = -\sqrt{2}$ and $\tau_2$ fixes $\sqrt{3}$ and $\sqrt{5}$. Applying it twice, we get $\tau^2_2(\sqrt{2}) = -(-\sqrt{2}) = \sqrt{2}$. Since $\tau_2^2$ fixes the generators $\sqrt{2}, \sqrt{3}, \sqrt{5}$, it fixes every element in $E$. Thus $\tau_2^2 = \iota$. Since $\tau_2 \neq \iota$, the order is 2. The same logic applies to $\tau_3$ and $\tau_5$.
\end{solution}

\begin{solution}[(ii)]
  The subgroup $H = \langle \tau_2, \tau_3, \tau_5 \rangle$ consists of all compositions of these maps. Since they commute (e.g., $\tau_2\tau_3 = \tau_3\tau_2$) and each has order 2, the elements are:
  \[%
    H = \{ \iota, \tau_2, \tau_3, \tau_5, \tau_2\tau_3, \tau_2\tau_5, \tau_3\tau_5, \tau_2\tau_3\tau_5 \}
  .\]%
  Letting $\tau_{ijk} = \tau_i\tau_j\dots$, the group is isomorphic to $\Z_2 \times \Z_2 \times \Z_2$.

\begin{solution}[(iii)]
  Any automorphism in $G(E/\Q)$ must send $\sqrt{2}$, $\sqrt{3}$, and $\sqrt{5}$ to two possible values (i.e., $\sqrt{2} \mapsto \pm \sqrt{2}$, $\sqrt{3} \mapsto \pm \sqrt{3}$, and $\sqrt{5} \mapsto \pm \sqrt{5}$). Since there are 8 possible combinations of signs, there are at most 8 automorphisms in $G(E/\Q)$. Since $H$ has 8 elements, we must have $H = G(E/\Q)$.
\end{solution}
