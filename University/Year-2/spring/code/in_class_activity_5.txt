5. Please explain how we can modify/refactor this code to make it a more generalizable function.

The current function is hardcoded for base 2 (binary) because it always uses 2**index. To make it generalizable, you would add a base parameter so it can convert from any base (octal, hexadecimal, etc.) to decimal:
```python
def to_dec(st, base):
    dec_value = 0
    index = 0
    while index < len(st):
        digit = st[-(index + 1)]
        dec_value += int(digit) * (base ** index)
        index += 1
    return dec_value
```
Now the same function handles any base; for example, to_dec("127", 8) solves Question 4, and to_dec("1011", 2) still works for binary.
